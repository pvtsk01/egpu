Jetson Nano Program API

This deployment preserves the original text API routes.

  • /list — list all programs
  • /week/1 — program 1 source code
  • /week/12 — program 12 source code

Use curl from a terminal:

curl https://YOUR-DOMAIN.vercel.app/list
curl https://YOUR-DOMAIN.vercel.app/week/1

Replace YOUR-DOMAIN with your deployed Vercel domain.
